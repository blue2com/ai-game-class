# 랭킹 버전 구글 시트 연결하기 (5분)

랭킹 버전 파일: `rps-rank.html`, `sudoku-rank.html`, `ranking.html`
(기존 `rps.html`, `sudoku.html`은 랭킹 없이 그대로 유지)

## 1. 시트 만들기
1. https://sheets.new 에서 새 구글 시트를 만들고 이름을 `게임 랭킹` 등으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 모두 지우고 [Code.gs](Code.gs) 내용을 붙여넣은 뒤 **저장**(💾)합니다.

## 2. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 ⚙ → **웹 앱** 선택
3. 설정
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** ← 학생들이 로그인 없이 쓰려면 꼭 이것
4. **배포** → 권한 승인 창에서 계정 선택
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**
     (내가 만든 스크립트라 괜찮습니다)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 3. 게임에 연결
위 URL을 Claude에게 알려 주면 세 파일의 `RANK_URL`에 넣어서 다시 올려 줍니다.

## 수업 중 관리
- 시트의 `rps`, `sudoku` 탭에서 기록을 실시간으로 볼 수 있습니다.
- 이상한 이름이나 기록은 해당 행을 지우면 됩니다.
- 새 반 수업 전에 초기화하려면 `rps`, `sudoku` 탭을 지우세요. 다음 기록이 들어오면 자동으로 다시 생깁니다.
- `Code.gs`를 고친 경우 **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포**를 해야 반영됩니다.

## 규칙 바꾸기
| 바꿀 것 | 위치 |
|---|---|
| 가위바위보 도전 횟수 | `Code.gs`의 `maxAttempts: 3` + `rps-rank.html`의 `MAX_ATTEMPTS` |
| 가위바위보 라운드 수 | `rps-rank.html`의 `ROUNDS` (바꾸면 `Code.gs`의 `max: 30`도 라운드×3으로) |
| 스도쿠 실수 벌점 | `sudoku-rank.html`의 `PENALTY` |
